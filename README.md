# NB-Remote

Remote desktop access from phone to company NB via a WebSocket relay.

## Architecture

```
Phone (Chrome)  ──WSS 443──▶  Relay (Render.com)  ◀──WSS 443──  NB (Python)
   │                            Free web service                    │
   │  See desktop                (just forwards)                    │ Captures screen
   │  Touch to control                                              │ Replays input
```

- **Relay** (`server.py`): Runs on Render.com free tier. Pure WebSocket bridge.
- **NB Client** (`client/nb_client.py`): Runs on the company laptop. Uses Python's `ssl` module which trusts the Windows CA store, passing through corporate SSL inspection.
- **Phone UI** (`static/index.html`): Pure HTML/JS, runs in Chrome. Shows the desktop and sends touch/keyboard events.

## Setup

### 1. Deploy relay to Render

- Push this repo to GitHub
- On Render: New → Web Service → connect this repo
- Render auto-detects `requirements.txt` and `server.py`
- Note the URL (e.g. `https://nb-remote-xxxx.onrender.com`)
- Go to Environment → copy the `NB_REMOTE_TOKEN` value

### 2. Run client on NB

```cmd
cd client
pip install -r requirements.txt
set NB_REMOTE_RELAY=https://nb-remote-xxxx.onrender.com
set NB_REMOTE_TOKEN=your-token-here
python nb_client.py
```

Or edit and double-click `start.bat`.

### 3. Open on phone

Open Chrome → go to `https://nb-remote-xxxx.onrender.com`

## Controls

- **Tap** = left click
- **🖱 Right** button then tap = right click  
- **⌨ Keyboard** = opens phone keyboard for typing
- **Esc / Tab / Enter / Win** = toolbar buttons

## Environment Variables

### Relay (Render)
| Variable | Description |
|---|---|
| `NB_REMOTE_TOKEN` | Auth token (auto-generated by Render) |

### NB Client
| Variable | Default | Description |
|---|---|---|
| `NB_REMOTE_RELAY` | (required) | Relay URL |
| `NB_REMOTE_TOKEN` | (required) | Auth token |
| `NB_REMOTE_FPS` | 5 | Frames per second |
| `NB_REMOTE_QUALITY` | 50 | JPEG quality (1-100) |
